Operator login

Every test whose app traffic ran as paced UDP bursts (engine udp_burst), marked or not, all days together. A sweep runs the same workload once per marking with everything else equal (scripts/fieldtest/dscp_sweep.sh MODE=video|upload|voice). The sender marks each datagram; the receiver logs the marking that arrived — downlink: the server marks, the phone reads; uplink: the phone marks, the server reads. Outcome: kept the marking arrived unchanged, re-marked it arrived as another class, bleached it arrived as 0, mixed no single value in 90 % of datagrams. Loss: datagrams that never arrived; extra delay: above that stream's own minimum (the clocks' offset cancels); IPDV: how much the spacing of consecutive datagrams changed on the way.
